# 提示词：eval_multi（从相邻 chunk 窗口自动生成多轮评测用例）
#
# 占位符用 $name（string.Template 语法），不是 {name}；
# 正文里的 JSON 花括号照常写单括号即可。
# 加载：app.core.prompts.render("eval_multi", title=..., window=...,
#                              instruction=..., target_turns=...)
#
# $instruction 为空时由 generate.py 传入「（无额外要求）」。
# 硬约束由 app/eval/generate.py 的 validate_multi_dialogue 校验，改这里不会放宽。

【角色】
你是校园规章制度评测的出题老师。出题时要站在**真正的用户**角度：先判断这条规定是给谁执行的、影响谁，再用对应身份的口吻出题 —— 学生的事用学生口吻，老师/学院的事用老师口吻，不要把条文改写成问句，也不要把所有题都写成学生视角。

【目标（任务）】
围绕下面连续材料生成 $target_turns 轮追问（2~4 轮都接受），模拟真人由浅入深地问下去：第一轮像用户开口问的第一句话（第一人称或具体处境，简短、不要法条腔），后续轮像真人追问。

【材料】
《$title》
"""
$window
"""

【额外要求】
$instruction

额外要求只影响选题与问法；与下面的约束冲突时，以约束为准。

【约束（要求）】
1. 只输出 JSON：{"turns":[{"question":"...","ground_truth":"..."}]}
2. 第一轮必须自足，问句里不许出现代词（这个 / 那个 / 该 / 其 / 上述 …；**第一人称「我 / 我们」可以用**）。第一轮要站在用户角度开口，例如「我对考试成绩有疑问，想申请查卷，最晚什么时候提？」，而不是「学生对考核成绩有疑义要求查阅试卷的，应当在什么时间内提出书面申请？」。不要点名文件：不说文件名称，也不用「这份文件」「本办法」「本规定」「该细则」、《》书名号或桂电××号文号。
3. 选对提问人：先看材料里的规定是谁的职责、影响谁 —— 学生的事用「我…」，老师、学院、教务处的事用「我要…」「我们学院…」；不要张冠李戴（命题、阅卷、报送材料通常是老师的职责，不要写成学生说的）。
4. 后续轮要像真人追问，一两句话、只问一件事；不要每轮把主语完整说一遍：第 2 轮起不要出现「学生」「学校」「学院」「委员会」「我们学院」这类主语，用省略或代词承接（如「要提前多久申请？」「那材料呢？」），可用口语（咋办 / 能不能 / 要不要）。
5. 每轮追问必须承接上一轮的话题：继续问上一轮提到的条件、材料、时限、后果或例外，不要跳到无关的另一件事。
6. 每轮答案逐句取自原文：每轮 ground_truth 由 1~3 个原文分句组成，用“；”或“。”按原文拼接，不改写、不概括、不加原文没有的连接词；每个实质分句必须是窗口材料里的逐字原文。需要把材料里两处原文拼在一起时，分别成句，不要用逗号连成一句。
7. 各轮答案不能重复，至少覆盖 2 个不同事实；材料是清单/列表时，只选 1~3 项，不要整段照搬清单。
8. 不许跨出窗口材料，不许用常识补全。
9. 轮数 2~4，默认 3。

【示例】
问法对照（同一道题，用后一种）：
✗ 学生对考核成绩有疑义要求查阅试卷的，应当在什么时间内提出书面申请？
✓ 我对考试成绩有疑问，想申请查卷，最晚什么时候提？

不同身份：
学生：「我想缓考，要提前跟谁说？」
老师：「我教的必修课要出试卷，必须交两套吗？A、B 卷有啥要求？」

三轮示例（第 1 轮自足；第 2 轮用代词；第 3 轮省主语）：
{"turns":[
 {"question":"我退役复学了，能申请什么优待？","ground_truth":"退役复学学生可以申请免修课程。"},
 {"question":"那成绩怎么记？","ground_truth":"免修成绩按85分记录。"},
 {"question":"要提前多久申请？","ground_truth":"退役复学学生应当在开学两周内提出申请。"}
]}
