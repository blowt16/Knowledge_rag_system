## 三、已知问题

### 问题 1：七份文档首页文字层错乱，且有两种不同的失效模式

红头文件封面页为**竖排排版**，PDF 写入文字层时顺序出错。2026-10-15 用逐份原始文字排查后，确认**不是一种问题，而是两种**：

**模式 A · 字符级倒序**（整页逐字反写）

```
实际提取： ） 布 发 开 公 件 此 （ 日 0 1 月 7 年 5 2 0 2 学 大 技 科 子 电 林 桂
正常顺序：  桂 林 电 子 科 技 大 学 2 0 2 5 年 7 月 1 0 日 （ 此 件 公 开 发 布 ）
```

**模式 B · 行序倒置**（行内文字正常，但整页的行从上到下反了）

```
实际提取： 日 9 月 8 年 2019 / 桂林电子科技大学 / 认真遵照执行。 / 现将《…》印发给你们，请 / 各单位、各部门：
正常顺序： 各单位、各部门： / 现将《…》印发给你们，请 / 认真遵照执行。 / 桂林电子科技大学 / 2019 年 8 月 9 日
```

**受影响清单与本批规律**：

| 模式 | 文件 | 来源 |
|---|---|---|
| A 字符级倒序 | 07、08、09、12、13 | 信息公开网 |
| B 行序倒置 | 06、10 | 信息公开网 |
| 正常 | 01–05、11、14 | 教务处 |
| 正常 | 15 | 校团委 |

> **规律**：**信息公开网（pubinfo）的公文封面全部错乱**，教务处和校团委的则正常。新增采集时可按来源预判。

**影响范围**：仅第 1 页（封面）。**第 2 页起正文文字层正常**，不影响文档主体内容。

**对 RAG 系统的影响**：封面页错乱文本进入分块流程后会形成噪声块，污染向量索引与 BM25 索引。

**处理建议**（在文档摄入的文本清洗环节）：
- 方案 A：模式 A 检测「逐字空格分隔 + 关键短语反写」特征（如 `学大技科子电林桂`），命中则丢弃该页或反转还原
- 方案 B：模式 B 检测「首行以日期结尾、末行以『各单位、各部门』开头」的自相矛盾特征，命中则按行反转
- 方案 C：**最省事**——封面页不含实质规则条文，直接跳过第 1 页（正文从第 2 页起）
- 注意：模式 A 的还原必须**按字符**反转、模式 B 必须**按行**反转，用错方向会得到更乱的文本。切勿用「整页字符反转」一刀切——对模式 B 的 06、10 会直接毁掉本已正常的行内文字。

### 问题 2：文件命名中的文号使用简写

为兼容文件系统与命令行，文件名中的文号做了简化（`〔〕` → 无、`号` 保留），例如 `桂电教〔2021〕6号` 写作 `桂电教2021-6号`。**正式文号以上表「内容核对结果」列为准**，做引用溯源时应使用正式文号。

2. **下载方式**：`bsk download` 对 PDF 链接无效——浏览器以内置阅读器打开 PDF，不触发下载事件。改用「提取 PDF 直链 → 直接下载」。
   - 补充（2026-10-15）：`_upload` 直链对 **HEAD 请求返回 403**，但对 GET 正常返回 200。别用 `curl -I` 探测可下载性，会误判成「下不了」。带上浏览器 User-Agent 即可 GET 成功。
3. **PDF 直链有两种形态**，采集时需分别处理：
   - 附件型：页面 HTML 中的 `<a href="/_upload/article/files/.../xxx.pdf">`
   - 内嵌型：页面中 `<iframe class="wp_pdf_player" src="...?file=/_upload/article/files/.../xxx.pdf">`
