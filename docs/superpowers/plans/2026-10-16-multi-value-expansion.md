## 1. 它解决什么

doc 12《第二课堂成绩单》里有这样一类行：**一格放了多个分值，另一格放了多个等级，两者按位置一一对应。**

```
等级格：特等奖（金奖）、一、二、三等奖
学分格：30、20、15、10分/项
        ↓ 按位置对应
特等奖=30、一等奖=20、二等奖=15、三等奖=10
```

**现状：这个对应关系没有任何地方记录。** 两格是彼此独立的字符串，模型要答「二等奖多少分」，得自己跨两格数位置。

**sc-06「文体竞赛国家级二等奖多少分」拒答的直接原因就是它。**

### 实测效果（真实 reranker，阈值 0.3）

| 行 | 查询 | 现状 | 展开后 | 变化 |
|---|---|---|---|---|
| 文体竞赛·国家级（sc-06） | 国家级二等奖加多少分 | 0.2185 ✗ | **0.5082 ✅** | **+0.290** |
| 挑战杯 A类·国家级 | 国家级一等奖加多少分 | 0.4776 ✅ | **0.8094 ✅** | +0.332 |
| 志愿服务大赛·国家级 | 国家级金奖加多少分 | 0.4948 ✅ | **0.6805 ✅** | +0.186 |

（注：只测了这 3 行 × 每行 1 个查询；其余 13 行未逐个验证，见 §7。）

## 2. 适用范围与边界（**审核重点**）

### 2.1 会处理的（in scope）

**同时满足以下全部条件，才展开：**

| # | 条件 | 判据 |
|---|---|---|
| 1 | 存在一个**学分格** | 该格**全串**匹配 `^[\d、.\s]+分[/／]\S*$`（纯数字 + 顿号 + `分/单位`），例如 `30、20、15、10分/项` |
| 2 | 该格**至少 2 个值** | 按 `、`/`，` 切分后 ≥2 项。单值行**不碰** |
| 3 | 左侧 ≤2 格内存在**等级格** | 先看左邻 1 格，不匹配再看左邻 2 格。**不向更左找** |
| 4 | 等级格的项能全部识别为等级 | 每个项去掉括号后匹配 `特等奖｜金奖｜银奖｜铜奖｜优胜奖｜国家级｜区级｜校级｜院级｜[一二三四五](等奖?)?` |
| 5 | **项数相等** | 等级项数 == 学分项数。不等 → **不展开** |

### 2.2 明确不处理的（out of scope）

| 情况 | 为什么不处理 |
|---|---|
| **列数漂移**（「获奖等级」在 p9–p12 成了独立列） | 那是「列义恢复」问题，另一套方案 |
| **单值学分**（`5分/项`） | 没有东西可展开。**98 行里的 82 行属于这类，原样不动** |
| **不是「等级↔学分」配对的多值格**（如岗位名 `各校级学生组织副职、各学生社团副职`） | 它们的多值不是等级枚举 |
| **等级格在左邻 2 格之外** | 不做远距离推断，宁可漏做 |
| **项数不等**（例如等级 3 项、学分 1 项） | 可能是合并单元格残留，猜就是错标 |
| **`列4：其他` 这类垃圾单元格** | 本次不碰（见 §6 未决项） |
| **doc 11 的全部表** | 实测 **0 行**多值学分，无需处理 |

### 2.3 覆盖面（实测）

| 文档 | 含学分格的数据行 | 多值行 | 占比 |
|---|---|---|---|
| doc 12 | 98 | **16** | **16%** |
| doc 11 | — | **0** | 0% |

**即：98 行里只改 16 行，其余 82 行一字不动。**

## 3. 算法

### 3.1 等级项识别（含省略写法）

**这是唯一有坑的地方，必须按此实现：**

`一、二、三等奖` 是**省略写法** —— 只有最后一个带「等奖」，前两个是裸的 `一`、`二`。

```
切分： ["一", "二", "三等奖"]
        ↑ 裸的，正则必须允许
```

用的正则：

```
TOKEN = (特等奖|金奖|银奖|铜奖|优胜奖|国家级|区级|校级|院级|[一二三四五](等奖?)?)$
```

`[一二三四五](等奖?)?` 里的 `(等奖?)?` 必须有 —— 少了它，`一`、`二` 识别不出来，展开会失败。
（实测：加不加这一处，16 行里只能展开 5 行 vs 16 行。）

**取最长全等级后缀**：从右往左尝试，找出最长的、每一项都像等级的后缀。
这样 `获国家级奖项一、二、三等奖` 也能识别（第一项带前缀，但仍以等级结尾）。

### 3.2 展开

```
学分值：[30, 20, 15, 10分/项]
等级：  [特等奖, 一等奖, 二等奖, 三等奖]
单位后缀：取最后一个值的「分/…」部分 → 分/项

输出：特等奖30分/项；一等奖20分/项；二等奖15分/项；三等奖10分/项
```

**显示清洗（只影响输出，不影响识别）：**

| 输入项 | 输出 |
|---|---|
| `一`、`二`、`三` | `一等奖`、`二等奖`、`三等奖` |
| `获国家级奖项一` | `一等奖`（去掉前缀） |
| `特等奖（金奖）` | **保留括号** → `特等奖（金奖）30分/项`（见 §6 待定项 1） |

### 3.3 落点

在 `serialize_groups` 里，**在「行 → 文本」这一步之前**对单元格做展开。
**不改变**分组、预算、`【表头】` 哨兵、`列N` vs 列名的选择——它只替换一个格子的内容。

## 4. 安全阀

| 情形 | 行为 |
|---|---|
| 任一条件（§2.1 的 1–5）不满足 | **原样返回，不展开** |
| 各项的单位后缀不一致（如 `15分/项、10分/次`） | **不展开**（未在语料中观察到，但不能猜） |
| 展开后文本长度 > 原格 3 倍 | **不展开**（防异常输入撑爆预算） |
| 等级项识别出 0 项 | 不展开 |

**原则：不确定就不做。错标的代价远大于漏做。**

## 6. 待审核的三个决定

### 待定项 1：`特等奖（金奖）` 的括号保不保留？

- **保留**：`特等奖（金奖）30分/项` —— 「金奖」这个搜索词还在，用户问「金奖」也能命中
- **去掉**：`特等奖30分/项` —— 更短更干净，但我实测时用的就是这个（0.8094）

**我的建议：保留。** 丢掉的同义词会影响检索。但要重测一次确认分数不受影响。

### 待定项 2：展开后，原来的等级格要不要保留？

现在是**保留**的，所以同一信息在行里出现两次（等级格一次、展开里一次）。去掉能缩短文本，但可能影响「获国家级奖项」这类前缀的检索匹配。

**我的建议：保留原等级格，只替换学分格。** 改动最小、最容易回退。

### 待定项 3：要不要顺带清掉 `列4：其他` 这类垃圾单元格？

sc-06 那行是 `列3：获国家级奖项一、二、三等奖｜列4：其他｜列5：18、15、12分/项`。
`列4：其他` 是 pymupdf 网格的残余，**没有信息量，可能干扰模型**。

**但清它属于另一个改动**（单元格清洗），且判断「哪些是垃圾」有风险。**我的建议：本次不做，记录在案。**

## 9. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| **等级项识别靠启发式** | 若某表出现新的等级写法（如 `A/B/C 档`），会漏展开 | 漏展开是原样保留，**不会错标** |
