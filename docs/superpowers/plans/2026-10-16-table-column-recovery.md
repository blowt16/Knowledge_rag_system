# 表格列义恢复 + 自然句序列化 — 改造方案（方案乙）

> 状态：**方案待评审，未实施**。本文档是设计 + 验证方案，不是可直接执行的 TDD 任务书。
> 前置结论来自 2026-10-15/16 的实测，出处见 §1。

---

## 1. 为什么做这个

### 1.1 现状的病因（已实测）

doc 12《第二课堂成绩单》的评分表跨 5 页，**第 8 页 6 列、第 9–12 页 7 列**（多的「获奖等级」列承载真实数据）。
此前按「列数不符时绝不按下标配列名」的裁定，这些行走**位置标签**（`列4：大学英语六级｜列5：5分/项`）。

实测后果：

| 证据 | 数值 |
|---|---|
| 同一主题（英语六级）的两块，只是序列化形态不同 | doc 11（**真列名** `类别/分值`）重排 **0.2196** vs doc 12（**位置标签**）**0.0645** —— **差 3.4 倍** |
| 含答案的块在检索候选池里的位置 | 向量路第 1–3、BM25 路第 1–3、RRF 后第 1–4 |
| 同一块**重排后**的位置 | **第 6，0.0645 分**，被 `min_score=0.3` 砍掉 |
| 用户问题「英语六级能加多少二课分」的结果 | 拒答（`insufficient_evidence`） |

**结论：检索能捞到，是重排把它埋了；而重排埋它的主要原因之一，是位置标签抹掉了列名这个语义锚点。**

### 1.2 为什么「直接改成自然句」不够（已实测，推翻我先前说法）

用机械模板把 `列N：值｜列N：值` 换成自然句后重排：

| 行 | 现状（位置标签） | 机械自然句 |
|---|---|---|
| 英语六级 | 0.1512 ✗ | **0.3899 ✅** |
| 职业资格 | 0.0732 ✗ | 0.0788 ✗ |
| 社团副职 | 0.8192 ✅ | 0.9560 ✅ |

**能救一部分，救不了全部。** 因为不知道「哪一格是分值、哪一格是单位」时，所谓自然句只是把一串值用逗号连起来。
（注：我此前给出的 `0.9975` 是一次**手写**的理想文案，不是机械模板能达到的水平，该数字已作废。）

### 1.3 可行性地基（已实测）

对 doc 12 第 9/10 页的 7 列做内容画像：

| 列 | 学分值占比 | 部门词占比 | 长句占比 | 短词占比 | 等级词占比 | 对应的表头 |
|---|---|---|---|---|---|---|
| 列0 | 0 | 0 | 0 | — | 0 | 课程类别（合并单元格，全列仅 1 个值） |
| 列1 | 0 | 0 | 0.33 | 0.44–0.67 | 0 | 课程项目 |
| 列2 | 0 | 0.05 | 0.11–0.16 | 0.42–0.58 | 0.11–0.53 | 课程内容 |
| 列3 | 0 | 0 | 0 | 0.75–1.00 | 0.33–0.53 | **无表头**（新增的「获奖等级」） |
| **列4** | **1.00** | 0 | 0 | 0.75–0.92 | 0 | **参考学分** |
| **列5** | 0 | **1.00** | 0 | 0.60–0.67 | 0 | **开课单位** |
| 列6 | 0 | 0.43–0.71 | 0 | 0 | 0 | 获得学分方式 |

**两列最关键的角色（参考学分、开课单位）用内容类型可以 100% 精确识别。** 这就是本方案的地基。

## 2. 目标与非目标

### 目标

1. 把「列数漂移」的表恢复出**可信的列义**，不再对整表使用 `列N` 占位符。
2. 把每一条数据行渲染成**可读的自然句**，让重排分从 0.06 量级回到 0.2+ 量级。
3. **在动索引之前**用离线 A/B 证明它有效；无效就不改。

### 非目标（明确不做）

- **不解决 doc 11 / doc 12 的语义混淆**（同一张 CET6 证书，创新创业学分 50 分 vs 二课分 5 分/项）。那是「近邻文档区分」问题，需要另一套信号（文档标题、口径词），本方案不碰。
- **不改 rerank 阈值**。本方案的前提是「让正确块自己爬上去」，不是放宽门槛。
- **不改检索架构**（不引入新索引、不改 RRF）。
- 不追求把手写文案级别的 0.99 分复现出来——机械模板做不到，也不该假装能做到。

## 3. 设计

### 3.1 列角色识别 `identify_roles(headers, rows) -> dict[int, ColumnRole]`

**输入**：一张逻辑表（同页或续页继承后）的表头名列表 `headers`（可能比数据列少）与数据行 `rows`（已 `normalize_grid` + `forward_fill`）。

**输出**：每个数据列的角色，取值 `类别 | 项目 | 内容 | 分值 | 单位 | 方式 | 未命名 | 未知`。

**步骤**（按置信度从高到低，先做高置信锚定，再做低位补齐）：

```
① 数值型锚定（最硬）
   score_col = 唯一满足「该列非空值 100% 匹配 \d+(\.\d+)?\s*分」的列
   → 若表头里存在含「学分」「分值」「标准」的名字，配给它（优先「参考学分」）

② 单位型锚定
   dept_col = 唯一满足「该列非空值 ≥90% 含 学院|部（|处|团委|中心|党委」的列
   → 配给表头里含「单位」「部门」的名字

③ 方式型锚定
   way_col = 唯一满足「该列 ≥50% 的值长度 ≥20 且不含 分/」的列
   → 配给表头里含「方式」「获取」的名字

④ 左锚补齐（用于剩下的表头）
   把剩余表头按原顺序，依次配给**剩余的最左**数据列
   —— 实测 doc 12：剩余表头 [课程类别, 课程项目, 课程内容] 配给 列0/列1/列2，正确

⑤ 剩余数据列 → 标记为「未命名」
   —— doc 12 的列3（获奖等级）落到这里，正确
```

**置信度**：①②③ 命中的列记 `high`；④ 补齐的记 `medium`；⑤ 记 `none`。
**任一锚定出现歧义（多列同时满足）→ 该表整体降级**（见 §3.4）。

### 3.2 自然句渲染 `render_sentence(roles, values)`

**模板（有未命名列时，doc 12 的形态）**：

```
{类别} - {项目} - {内容}：{未命名列的值}，参考学分 {分值}，{单位}（{方式}）
```

实例：

```
技能特长 - 语言类证书 - 大学英语及专业英语水平测试：大学英语六级，参考学分 5分/项，各学院（大学英语四级、艺术类专业英语三级、大学英语六级由各学院通过系统统一导入赋予学分）
```

**模板（无未命名列时，doc 12 第 8 页与 doc 11 的形态）**：

```
{类别} - {项目}：{内容}，参考学分 {分值}，{单位}（{方式}）
```

实例：

```
思想政治与道德修养 - 社会主义核心价值观教育：完成相应培训课时，参考学分 5分/学期，学工部（处）、各学院（每学期结束，由各学院团委通过系统管理端统一导入赋予学分）
```

**规则**：

- 拼不出的角色（`未知`）在句中省略，不留空槽。
- `方式` 列如果超过 60 字，截断到 60 字加省略号——实测该列常是一整段说明，会把整句稀释（这也是「去掉噪声表头后重排分涨 2.4 倍」的同类问题）。
- **不保留 `【表头】` 行**。实测：去掉那行后同一块重排分从 0.0645 → 0.1576（**2.4 倍**）；它把列名重复了一遍，对读句子的重排器是纯噪声。
  ⚠️ 但这会破坏 Task 6 的 `table_atomic_ranges`（它靠 `【表头】` 定位）。**替代方案**：改用另一个哨兵（如 `〖表〗`）仍标记组边界，但**不重复列名**；或让 `serialize_groups` 直接产出区间给 pipeline。

### 3.3 分组

沿用现有 `serialize_groups` 的预算逻辑（表头/前缀先扣预算、单行超预算自成一组）。**分组参数不变**，只替换「行 → 文本」这一层。

### 3.4 回退（安全阀）

| 情形 | 回退行为 |
|---|---|
| ① 或 ② 锚定失败/歧义 | 该表整体用**现状位置标签**（保持已有行为，不冒险） |
| 角色识别成功但某列 `未知` | 该列在句中省略，并在 chunk 尾部附 `（有 N 列未识别）` |
| 自然句渲染后长度异常（>2× 原长） | 退回现状 |

**原则不变：失败是降级，不是破坏。** 绝不因为识别不确定就猜一个列名贴上去——那正是本项目要消灭的「自信的错误标注」。

## 4. 验证方案（**必须先做，通过才动索引**）

### 4.1 离线 A/B（不动索引、不改代码）

写一个一次性脚本，对**同一批真实表行**渲染两种形态，用真实 reranker 打分：

- 形态 A：现状（位置标签键值行 + `【表头】` 行）
- 形态 B：本方案（自然句，无 `【表头】` 行）

对**全部 10 道评测题**（sc-01…sc-10）各自对应的目标行，各打一次分，记录：

| 指标 | 通过线 |
|---|---|
| 目标块重排分 ≥ 0.3 的题数 | 从现在的 **1/6**（只有 sc-09 那类天然高分的）提升到 **≥4/6** |
| 目标块重排分的中位数 | 从 **0.06** 提升到 **≥0.3** |
| 非目标行的分数变化 | **不得显著下降**（防止为了救几行把别处搞坏） |

### 4.2 门禁

**4.1 不达标 → 方案不上线**，回到讨论。不因为「设计看起来对」就直接改索引。

### 4.3 通过后

1. 改 `serialize_groups`（保留旧实现，用配置开关切换，便于对照回滚）。
2. 重跑两份含表格文档入库。
3. 在**新口径**下重跑评测，与改造前对比。
4. 写进 `corpus/guet/README.md`。

## 5. 风险与已知限制

| 风险 | 影响 | 缓解 |
|---|---|---|
| **左锚补齐是启发式** | 若某页多出来的列在中间而非尾部，`④` 会把后续表头整体右移一格 —— **正是当初裁定要避免的错误标注** | 只在 ①②③ 高置信锚定成功**且**剩余列数与剩余表头数一致时才启用 ④；否则整表降级到位置标签 |
| 只覆盖 doc 12 这类表 | doc 11 已经对齐，收益只有 doc 12 的 83 行 | 可接受；doc 11 本就没问题 |
| 不解决 doc 11/doc 12 混淆 | 用户问「二课分」仍可能被 doc 11 的 50 分干扰 | 明确列为非目标，另立方案 |
| `【表头】` 哨兵移除 | 破坏 Task 6 的 `table_atomic_ranges` 与 `clean.py` 的豁免规则 | 见 §3.2：换哨兵或直接产出区间；**必须同步改 T5/T6 的接口与测试** |
| 自然句模板可能丢信息 | 句式固定，某些列（如「备注」）会显得突兀 | 现状保留回退；模板只对识别出角色的列生效 |

## 7. 一句话总结

**方案乙 = 先用「内容类型」把漂移表的列义认出来（分值、单位两列可 100% 精确识别），再据此把每行渲染成自然句；`【表头】` 那行要去掉（实测它让重排分掉 2.4 倍）。**

**但它必须先在离线 A/B 里达标才准动索引**——因为上一轮的教训就是「设计看起来对、指标反而降」。
